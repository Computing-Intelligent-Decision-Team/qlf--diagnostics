# 融智芯客户咨询工作台设计

## 目标

在现有“服务详情”页基础上，为三类服务的“服务咨询”按钮增加一个简洁的客户视角咨询入口。页面用于展示尚未开始沟通时的静态空白工作台，不连接后端，也不提供实际聊天能力。

## 用户流程

1. 客户在服务详情页查看前端、后端或定制化服务。
2. 客户点击对应服务的“服务咨询”。
3. 页面进入 `/consultations/new?service=<service-id>`。
4. 工作台根据 `service-id` 展示所选意向服务，聊天区域保持空白。

“购买服务”保持现状，不接入此流程。

## 页面结构

咨询页使用沉浸式独立布局，不显示首页的常规导航。

### 顶部栏

- 融智芯 Logo、主标题和副标题。
- 返回服务详情。
- “我的咨询”按钮，仅展示，不响应点击。
- 保留“购买记录”、语言切换和登录/注册入口。

### 左栏

- 只显示当前咨询草稿。
- 标题根据入口显示为前端服务、后端服务或定制化服务咨询。
- 状态固定为“未开始”。

### 中间聊天区

- 不显示任何预置聊天、系统消息或资料卡片。
- 空白区域仅保留简短提示：“请描述您的芯片设计需求”。
- 底部展示输入框、附件按钮和发送按钮，但全部禁用。

### 右栏

- 意向服务：根据入口自动带入。
- 资料状态：显示“未提交”。
- 对接运营：显示“待分配”。
- 不显示订单编号、金额、交付时间、Agent 任务或内部运营操作。

## 视觉与响应式

- 延续现有融智芯蓝白企业级 SaaS 风格。
- 减少卡片、标签和辅助说明，保持留白和清晰层级。
- 桌面端使用左窄、中宽、右窄三栏。
- 窄屏按可用空间收起侧栏，优先保留空白聊天区，不产生横向溢出。

## 数据与边界

- 页面只读取 URL 中的 `service` 参数和现有静态服务数据。
- 无消息状态、文件状态、用户状态或持久化数据。
- 对未知 `service` 参数默认展示前端服务，并提供返回服务详情入口。
- 所有禁用控件使用原生 `disabled` 属性，不能通过键盘或鼠标触发。

## 验证

- 三个“服务咨询”按钮均进入咨询页，并显示正确的意向服务。
- “购买服务”行为不变。
- 页面不包含预置消息。
- 输入框、附件和发送控件均不可操作。
- “我的咨询”和“购买记录”同时可见，其中“我的咨询”不跳转。
- 桌面及窄屏布局无溢出。
- 自动化测试与生产构建通过。
